DevFlow ChatGPT Title Sync

Changes only the visible ChatGPT sidebar label for conversations that DevFlow has explicitly associated. Titles are never used as task, claim, or session identity.

Disable this to leave ChatGPT titles completely untouched.

Available tokens: {{project}}, {{taskId}}, {{taskTitle}}, {{chatAlias}}. Missing tokens are removed safely.

Only loopback addresses are accepted. The extension never sends the ChatGPT conversation ID to a remote host.
