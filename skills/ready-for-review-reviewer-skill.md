# Ready for Review Reviewer Compatibility Skill

## Compatibility role
This protected legacy skill id is retained because older UI and compatibility consumers may still request it directly.

It is non-authoritative and intentionally does not duplicate review policy.

For ChatGPT review of `ready-for-review` cards, corrected review assumptions, or embedded defects on existing tasks, load and follow `03-reviewer-core` as the single canonical reviewer policy.

If this compatibility document conflicts with `03-reviewer-core`, the canonical reviewer core wins and this pointer should be updated rather than growing a second policy copy.

Repository Git policy, checklist review, requirement authority, implementation evidence, pass/fail decisions, and bug-thread handling all belong to `03-reviewer-core`.
